# 🚀 Licitabot

Automatizando licitações com inteligência 🚀

## 🧠 Sobre
Licitabot é uma plataforma para automação e monitoramento de licitações, ajudando empresas a encontrar e analisar oportunidades de forma eficiente.

- frontend/
